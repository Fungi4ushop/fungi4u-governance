DONE_CRITERIA

Purpose:
Define when work is truly complete.

Principles:
- Implemented is not Done
- Validated is required
- Documentation must align
- State must reflect reality

--------------------------------------------------

Governance Work is Done when:

[ ] Decision approved
[ ] Decision recorded
[ ] Impact identified
[ ] Documents updated
[ ] Business State updated

--------------------------------------------------

Project Work is Done when:

[ ] Scope complete
[ ] Implementation complete
[ ] Validation complete
[ ] Documentation updated
[ ] State updated
[ ] Handover completed

--------------------------------------------------

Operational Work is Done when:

[ ] Change implemented
[ ] Operating procedure updated
[ ] Validation completed
[ ] Incident recorded if required

--------------------------------------------------

Technical Work is Done when:

[ ] Design completed
[ ] Configuration updated
[ ] Tested
[ ] Rollback possible
[ ] Documentation updated

--------------------------------------------------

Closure Rule:

Nothing closes until:
- documents updated
- business state updated
- open actions recorded
